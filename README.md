🍔 Mineiro - Hamburgueria Artesanal (Menu Digital integrado com whatsapp)

📄 Visão Geral do Projeto
Este projeto é um sistema de menu digital e vitrine de produtos desenvolvido para a hamburgueria "Mineiro". Foi projetado para ser uma solução de e-commerce estática, leve e otimizada, que permite aos clientes montar seus pedidos de forma intuitiva, calcular o frete automaticamente e finalizar a compra enviando a requisição formatada diretamente via WhatsApp.

🚀 Funcionalidades Principais
Menu Completo: Exibição organizada por categorias (Combos, Mineirinhos, Smashs, Acompanhamentos, Bebidas).

Carrinho de Compras Dinâmico: Adiciona, remove e atualiza itens em tempo real.

Cálculo de Frete por Bairro: O frete é calculado dinamicamente com base na seleção do bairro pelo cliente.

Gestão de Pagamento: Opções de pagamento configuráveis (PIX, Cartão, Dinheiro), incluindo campo para calcular o Troco.

Geração de Pedido via WhatsApp: Cria uma mensagem formatada e pronta para ser enviada diretamente para o número comercial, contendo todos os detalhes do pedido, cliente e endereço.

Toggle de Tema (Dark/Light Mode): Permite ao usuário alternar entre o tema escuro (padrão) e o tema claro.

💻 Tecnologias Utilizadas
O projeto foi desenvolvido utilizando tecnologias web padrão, visando máxima compatibilidade e desempenho:

HTML5: Estrutura semântica da página.

CSS3: Estilização e responsividade (incluindo variáveis de tema).

JavaScript (Vanilla JS): Lógica de manipulação do carrinho, cálculo de frete e geração da mensagem do WhatsApp.

Font Awesome: Para ícones sociais e do carrinho.

Google Analytics (G-WVJ8S7ZW6M): Para rastreamento de uso e desempenho da loja.
